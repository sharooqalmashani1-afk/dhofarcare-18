# DhofarCare — الملفات البديلة لمستودع dhofarcare-1

استبدلي الملفات الثلاثة على فرع `main` داخل GitHub:
1. `index.html`
2. `style.css`
3. `script.js`

يمكنك رفع الملفات الثلاثة في **Add file → Upload files** مع استبدال الموجود، ثم **Commit changes**. احتفظي بمجلد `assets` إن أردتِ، لكنه غير مطلوب في التصميم الجديد.

الموقع المتوقع بعد النشر: https://sharooqalmashani1-afk.github.io/dhofarcare-1/

الواجهة جاهزة ومتصلة برابط Cloudflare Worker الفعلي. عملية إرسال الحجز تعتمد على متغيرات Resend الخمسة التي ضبطتِها مسبقًا؛ المساعد يعتمد على Gemini. لا تختبري ببيانات خاصة حقيقية قبل اعتماد سياسة خصوصية وحماية من الروبوتات وحدود للطلبات.

## تجربة الحجز
الاسم، الهاتف العُماني، الولاية، نوع الخدمة، التاريخ والوقت إلزامية. عند نجاح قبول Resend للرسالة يظهر رقم الطلب. هذا **ليس تأكيدًا لموعد الفني** ولا إثبات وصول البريد إلى صندوق الوارد.

## تجربة AI
المحادثة ترسل الطلب عبر Cloudflare إلى Gemini. عند تعطل مفتاح Gemini أو تجاوز الحصة تظهر رسالة عدم توفر الخدمة، وليس ردًا افتراضيًا مضللًا.

## ملاحظات
- لا ترفعي `worker.js` أو مفاتيح API إلى GitHub Pages؛ يبقى Worker منشورًا فقط في Cloudflare.
- ينبغي توثيق نطاق بريد مرسل لاستخدام Resend مع مستلمين متعددين؛ `onboarding@resend.dev` للاختبار المحدود.
- Cloudflare Worker الحالي يسمح فقط لمصدر `https://sharooqalmashani1-afk.github.io`.
- لم تُضف قاعدة بيانات؛ يُرسل البريد ولا يُخزّن الحجز في لوحة إدارة.
